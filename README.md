# Letter from Spring · 雨季

一个清新文艺风格的「传讯」网页应用：和对方（默认角色 Nova）聊天，对方的每一句话都来自**字卡库**的随机组合，逐条发送，并附带拍一拍、表情包、emoji、状态更新、心情日历与语音来电等模拟事件。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（如 `letter-from-spring`）。
2. 把本目录下所有文件上传到仓库根目录（`index.html`、`src/`、`assets/`）。
3. 仓库 Settings → Pages → Source 选择 `main` 分支根目录，保存。
4. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 本地运行

直接双击 `index.html` 即可；或任意静态服务器（如 `python3 -m http.server`）。

## 功能一览

- **传讯**：发送消息后，对方按概率回复 1–3 张字卡（75% / 20% / 5%），每条字卡独立判定 20% 概率附带表情包、20% 概率附带 emoji（混合模式开：拼在文字前/后；关：单独一条）。
- **拍一拍**：回复流程 3% 概率触发「对方拍了拍你」；双击对方头像可拍一拍对方。
- **状态更新**：每隔 1~8 小时随机更新一次，状态库支持分组权重。
- **心情日历**：每天首次打开时 80% 概率记录一个心情（20% 留白），设置里可看月历。
- **来电**：每 15~60 分钟检查一次，25% 概率来电；主动拨打有 35% 概率被挂断。
- **设置**：后台挂活（循环轻音乐）、弹窗通知（开启即发送测试通知）、备份导出/导入、字卡库/状态库/表情库/心情库管理、角色改名。

## 数据说明

所有数据（聊天记录、字卡库、设置）保存在浏览器 `localStorage`，仅存本机。换设备或清理缓存前请先在设置里**导出备份**。

## 素材

`assets/` 内的头像与表情包贴纸为 AI 生成，可自由替换：头像命名为 `avatar-nova.png`（方形即可），贴纸命名为 `sticker-1.png` ~ `sticker-4.png`（透明底 PNG 效果最佳）。
